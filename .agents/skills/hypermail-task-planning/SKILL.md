# HyperMail Task Planning Skill

Before implementing any feature or task, every agent must define:
1. **Objective**: Concrete functional goal.
2. **Files in Scope**: Explicit list of files created or modified.
3. **Contracts Used**: Shared types referenced from `docs/contracts/`.
4. **Acceptance Criteria**: Verifiable requirements.
5. **Non-Goals / Exclusions**: What is explicitly out of scope for this task.
