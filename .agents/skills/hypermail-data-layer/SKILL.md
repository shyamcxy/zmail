# HyperMail Data Layer Skill

## 1. SQLite Configuration
- Use `rusqlite` with the `bundled` feature.
- Always execute PRAGMA settings on connection:
  ```sql
  PRAGMA journal_mode = WAL;
  PRAGMA synchronous = NORMAL;
  PRAGMA foreign_keys = ON;
  PRAGMA busy_timeout = 5000;
  ```

## 2. Search Engine
- **FTS5 Table**: Virtual table `messages_fts` indexing `subject`, `body_text`, `from_address`, and `from_name`.
- **Vector Search**: `sqlite-vec` extension storing 768-dimensional float embeddings generated by `nomic-embed-text`.
- **Hybrid Retrieval**: Combine FTS5 BM25 score with vector cosine distance using Reciprocal Rank Fusion (RRF).

## 3. Migrations
- Store migrations in sequential SQL files: `001_initial.sql`, `002_add_index.sql`.
- Track applied versions in a `_schema_migrations` table within a single transaction.
